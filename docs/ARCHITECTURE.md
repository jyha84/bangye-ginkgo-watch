# 구조와 데이터 흐름

## 프런트엔드

- `web/index.html`, `web/style.css`: 한국어 대시보드·반응형 화면·공통 버튼 스타일.
- `web/ui.js`: 탭 표시·ARIA·키보드 이동, 주소와 뒤로가기 복원, 3D 지연 로딩. CCTV 장면 가져오기는 3D 탭을 먼저 엽니다.
- `web/app.js`: Open-Meteo 날씨와 예보, 한국시간 날짜, 외부 검색 링크.
- `web/cctv.js`: `/api/cctv` 조회, 미디어 재생, 연결 안내와 전체 화면. 연결 오류 때만 복구 버튼을 표시합니다.
- `web/cctv-zoom.js`: Pointer Events로 1~4배 확대와 위치 이동. 슬라이더·초기화·화면 크기 변경과 동기화.
- `web/studio.js`: 로컬 사진·CCTV 캡처, 선택 영역과 잎 색 후보 분석, 확대 보정, 배경 은행잎.
- `web/tree3d.js`: Three.js 근사 수형, 색 비율 반영, 회전·확대·시점 이동.
- `web/directions.js`: 네이버 지도 앱 URL과 현재 위치 기반 카카오맵 길찾기.

사진과 선택 영역 분석은 브라우저에서 처리합니다. 위치는 버튼을 눌렀을 때만 확인하며, 선택한 지도 서비스로 전달합니다. 사진·위치를 저장하는 서버 API나 데이터베이스는 없습니다.

## CCTV 서버

| 경로 | 역할 |
| --- | --- |
| `GET /api/cctv` | ITS에서 반계 주변 카메라를 조회하고 이름에 ‘반계’가 있는 결과만 제공 |
| `GET /api/stream?t=…` | 서버가 발급한 암호화 티켓으로 HLS·영상 세그먼트 연결 |
| `GET /api/cctv-health` | ITS·날씨 서버 연결 진단. 키 승인 상태를 확정하는 기능은 아님 |
| `/`, 정적 자산 경로 | 빌드에 묶인 프런트엔드 제공 |

ITS 응답은 최대 60초 재사용합니다. 키는 서버 환경에서만 읽고, 브라우저에는 미디어의 원본 주소 대신 30분 유효한 암호화 티켓을 제공합니다. 미디어 리다이렉트는 최대 세 번 처리하며 출처·공개 URL·HTTPS 유지 조건을 검사합니다. 임의 URL을 받아 중계하는 API는 없습니다.

## 빌드와 독립 HTML

`build.mjs`는 정적 자산과 Worker 코드를 `dist/server/index.js`로 묶습니다. `export-html.mjs`는 CSS·스크립트·은행잎 이미지를 루트 HTML에 포함하고 서버용 CCTV 연결을 지도 안내로 바꿉니다.

원본 소스를 수정해도 이미 만들어진 `index.html`은 자동 갱신되지 않습니다. 내보내기를 다시 실행해야 합니다. 정적 호스팅에서 Worker 파일을 HTML처럼 올리면 CCTV가 실행되지 않습니다.

## 알려진 제약

- 3D는 해당 탭을 처음 열 때 불러오고 숨겨진 패널에서는 렌더링을 멈춥니다.
- 3D 모델은 넓은 수관·여러 줄기를 시각적으로 근사한 것이며 실측 형상은 아닙니다.
- 색 분석은 선택 영역·노출·역광·배경 물체의 영향을 받습니다.
- 선택 영역 보정은 최대 긴 변 2048px, 사진 작업 이미지는 최대 긴 변 2400px로 제한합니다.
- Three.js와 HLS.js는 CDN에서 불러옵니다. 날씨·지도도 외부 서비스에 의존합니다.
- 실제 CCTV, 지도 앱 설치 여부, 휴대폰 GPS와 인앱 브라우저 동작은 모의 테스트와 별개입니다.
- ITS 타임아웃은 키 오류와 다릅니다. 오류 메시지만 보고 인증키를 교체하지 않습니다.
- 독립 HTML에는 실시간 CCTV 서버가 없습니다. Pages로 올릴 경우 지도 안내가 제공됩니다.
