# 외부 서비스와 참고 자료

## 런타임 외부 서비스

- ITS 국가교통정보센터: https://www.its.go.kr/
- ITS CCTV API: `https://openapi.its.go.kr:9443/cctvInfo` (승인 키 필요)
- Open-Meteo: https://open-meteo.com/
- HLS.js 1.6.13: https://github.com/video-dev/hls.js (MIT)
- Three.js 0.180.0: https://github.com/mrdoob/three.js (MIT)
- 지도·CDN 서비스는 해당 제공자의 약관과 가용성을 따릅니다.

## 길찾기

- 네이버 지도 URL Scheme: https://guide.ncloud-docs.com/docs/maps-url-scheme
- 카카오 지도 URL: https://apis.map.kakao.com/web/guide/#mapurl
- 도착 좌표는 원주시 관광 안내의 ‘원주 반계리 은행나무’ 위치를 대조했습니다.
- 도착 좌표: 위도 `37.29420615216428`, 경도 `127.78839901238739`
- 자동차 길찾기를 기본으로 열고 다른 이동수단은 지도에서 변경합니다.

## 실제 수형 참고

- 원주시 관광 안내: https://www.wonju.go.kr/tour/viewTnResrceDataT.do?key=5477&resrceNo=4712
- 사진 참고: https://www.filmkorea.or.kr/location/location_view.jsp?id=352462&page=236
- 참고 기사: https://www.fnnews.com/news/202509291648076893

3D 수형은 참고 자료를 바탕으로 코드로 근사했습니다. 참고 사진 자체나 CCTV 영상은 이 저장소에서 재배포하지 않습니다. `web/ginkgo-leaf.png`는 이 프로젝트의 배경 효과에 사용하는 생성 이미지입니다.

새 공개 배포·상업적 재사용을 계획할 때는 외부 서비스와 자산의 이용 조건을 별도로 확인하세요. 이 백업은 외부 서비스의 이용 권한을 추가로 부여하지 않습니다.
